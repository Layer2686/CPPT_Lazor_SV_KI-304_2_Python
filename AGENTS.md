# Робота над лабораторними №6–7

Працюй українською. Використовуй [PLAN.md](PLAN.md) і README поточної
лабораторної. Студент пише предметну логіку, пояснює ключові рішення
й бере участь у перевірці. Допомагай з одним етапом за раз.

- До змін перевір гілку, стан робочого дерева і відповідний Issue.
  Зберігай незакомічені правки. Каталог `md/` локальний.
- Запускай тести, Ruff та збірку відповідного пакета. CLI wheel
  перевіряй в окремому venv і поза вихідним деревом.
- У PR вказуй фактичні результати. Для завершеного Issue використовуй
  `Closes #N`, для часткового — `Refs #N`. Злиття після рев’ю та
  зеленого CI актуального коміту. Публікація кінцевого звіту після
  погодження студента.
- Рольові промпти є в `ai/`. Для незалежної перевірки використовуй
  доступного агента-рецензента, якщо це дозволено в поточній сесії.
